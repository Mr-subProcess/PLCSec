# Technical references

The following primary or maintainer sources informed the protocol and security-control descriptions. PLCSEC is an independent assessment tool and is not endorsed by these organizations.

- NIST, *SP 800-82 Rev. 3: Guide to Operational Technology (OT) Security*: <https://csrc.nist.gov/pubs/sp/800/82/r3/final>
- OPC Foundation, *OPC UA Part 4: Services*: <https://reference.opcfoundation.org/specs/OPC-10000-4/full>
- OPC Foundation, *OPC UA Part 6: Mappings*: <https://reference.opcfoundation.org/specs/OPC-10000-6/full>
- ODVA, Rockwell Automation / Allen-Bradley Declaration of Conformity (CIP Vendor ID 1 example): <https://literature.rockwellautomation.com/idc/groups/literature/documents/ct/1756-ct155_-en-e.pdf>
- python-snap7 documentation, Client API: <https://python-snap7.readthedocs.io/en/stable/API/client.html>
- Scapy documentation: <https://scapy.readthedocs.io/>

Standards can change and vendor implementations differ. Re-check the applicable standard edition and vendor documentation before making operational decisions.
- OASIS, *STIX Version 2.1* (standard): <https://docs.oasis-open.org/cti/stix/v2.1/os/stix-v2.1-os.html>
- OASIS, *STIX Version 2.1 Errata 01*: <https://docs.oasis-open.org/cti/stix/v2.1/stix-v2.1.html>
- DNP Users Group, *DNP3 Primer*: <https://www.dnp.org/Portals/0/AboutUs/DNP3%20Primer%20Rev%20A.pdf>
- Xylem, *Protocol Translator DNP3 User Manual*, CRC frame construction overview: <https://www.xylem.com/siteassets/brand/flygt/resources/flygt-resources/protocol-translator-dnp3-user-manual.pdf>
- IETF Internet-Draft, *An Experimental Post-Quantum Cryptographic Profile for DNP3 Secure Authentication Version 5*, CRC-16/DNP parameters and check vector (draft, not a DNP3 conformance standard): <https://datatracker.ietf.org/doc/draft-liu-iotops-pqc-dnp-sav5/01/>
- Beckhoff, *IEC 60870-5-104 telegram structure*: <https://infosys.beckhoff.com/content/1033/tf6500_tc3_iec60870_5_10x/984444939.html>
- Weidmüller, *Interoperability IEC 60870-5-104*: <https://support.weidmueller.com/online-documentation/latest/322745/files/Interoperability60870/IEC60870-5-104/IEC60870-5-104.html>
- OpenText, *Implementing ArcSight Common Event Format (CEF)*: <https://www.microfocus.com/documentation/arcsight/arcsight-smartconnectors-24.1/pdfdoc/cef-implementation-standard/cef-implementation-standard.pdf>
